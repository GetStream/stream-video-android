getNotificationOwnedIncomingCallNotification

open fun getNotificationOwnedIncomingCallNotification(streamCallId: StreamCallId, ringingState: RingingState.Incoming, fullScreenPendingIntent: PendingIntent, contentPendingIntent: PendingIntent, acceptCallPendingIntent: PendingIntent, rejectCallPendingIntent: PendingIntent, callerName: String?, shouldHaveContentIntent: Boolean, payload: Map<String, Any?>): Notification?

Creates an incoming-call notification when the notification owns ringtone playback.

Override this method to customize notification-owned incoming-call notifications. The default implementation configures the ringing channel, looping ringtone flags, separate content and full-screen intents, and accept and reject actions. Replacing those properties may prevent the incoming ringtone or full-screen presentation from working.

Returning null suppresses both the incoming-call notification and its ringtone.

Parameters

streamCallId

The incoming call identifier.

ringingState

The current incoming ringing state.

fullScreenPendingIntent

Opens the incoming-call screen without dismissing the notification.

contentPendingIntent

Opens the incoming-call screen after a user taps the notification.

acceptCallPendingIntent

Accepts the incoming call.

rejectCallPendingIntent

Rejects the incoming call.

callerName

The caller name displayed in the notification.

shouldHaveContentIntent

Whether tapping the notification should open the call screen.

payload

The payload associated with the incoming-call notification.
